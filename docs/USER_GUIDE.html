assistant 使用手册

想找什么，直接告诉我

查产品、挑礼品、做图册，我来帮您。
您说需求，勾选喜欢的商品就行。

在 Codex 打开 assistant 项目，就可以聊天了。

  1. 1把资料给我

    把报价表、产品文件发给我，或者告诉我文件放在哪里。新资料可以随时加，已经加过的不用每次重发。

    “把这几份报价加进去，以后找产品用。”

  2. 2说说您想要什么

    大概多少钱、送给谁、有什么要求，说个大概也行。我会帮您理清，再找合适的商品。

    “找些一百元以内、过年送长辈的礼品。”

    资料里有几种价格时，我会先问清楚按哪种算。

  3. 3勾选喜欢的，交给我做图册

    我会打开选品页。您勾选想要的商品，再回到聊天里说：

    “选好了，帮我做成 PPT。”

    我会把选中的商品整理成一份图册，方便您发给客户。

不知道下一步，就叫我

“我不会用，带我一步一步来。”

我会先说眼前这一步，不用您记命令。想再看这份说明，就说“给我看使用手册”。

这些商品不合适，怎么办？

直接告诉我：“再便宜一点”“不要食品”“换一批看看”。我会根据您的新要求继续找。

想让别人先看看商品

点选品页右上角的分享图标，选好时间，再点“确认分享”。分享的是本页全部商品，别人只能查看。分享时，这台电脑要保持开机、联网。

想省一点消耗

默认用“正常档”。想省一点，可以说“用低消耗档”；想换回来，就说“用正常档”。需要您切换聊天模型时，我会提醒您。

页面打不开，或者还没装好

直接告诉我“页面打不开”或“帮我装好”，也可以把报错截图发给我。我会先检查，再告诉您接下来怎么做。

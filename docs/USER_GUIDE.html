assistant 使用手册

想办什么，直接告诉我

在 Codex 里说“打开工作台”，就能在网页里接着聊。

  1. 1说说您想办什么

    找商品、做图册、整理文字，都可以直接说。说个大概也行，我会帮您理清。

    “找些一百元以内、过年送长辈的礼品。”

  2. 2有新资料，就加进来

    点输入框旁的“加资料”，选文件，再告诉我怎么用。已经加入产品池的资料，不用每次重发。

    “这份报价加进去，以后找产品用。”

  3. 3勾选商品，做成图册

    商品会出现在聊天里。勾选喜欢的，点“做成图册”，做好后点“保存”就行。

    想看更多信息，点商品下方的“详情”。

不知道下一步，就叫我

“我不会用，带我一步一步来。”

我会先说眼前这一步，不用您记命令。想再看这份说明，就说“给我看使用手册”。

这些商品不合适，怎么办？

直接告诉我：“再便宜一点”“不要食品”“换一批看看”。我会根据您的新要求继续找。

想接着上次的选品做

点左上角的菜单，打开“最近办的事”，找到上次的内容，就能接着聊。

想让别人先看看商品

点选品页右上角的分享图标，选好时间，再点“确认分享”。等链接出来，点“复制链接”，再把链接发给对方。

分享的是本页全部商品，别人只能查看。分享时，这台电脑要保持开机、联网。

想省一点消耗

点右上角“设置和帮助”，把办事方式选成“低消耗”。下一件事开始使用。通常保持“正常”就好。

页面打不开，或者还没装好

直接告诉我“页面打不开”或“帮我装好”，也可以把报错截图发给我。我会先检查，再告诉您接下来怎么做。

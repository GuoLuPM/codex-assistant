# 多格式来源与 Codex 工作流

## 目标

由 Codex 理解表格语义，确定性工具处理读取、映射、检索和 PPT。减少整表读取与重复推理，不用供应商词表、文件名分支或失败样例堆规则。

## 已确认的通用缺口

真实来源存在行式表格、合并记录、重复表头和重复卡片；价格口径与列标题不能仅凭别名判断，图片可能是浮动图或单元格图片。

## 范围与职责

- 加入有分页/范围/字符预算的结构观察接口。
- 允许 Codex 给出本地导入映射，描述数据区、字段坐标、价格角色与图片列。覆盖行式和重复块式结构。
- 自动识别的旧表与显式映射共用一套记录投影和图片读取，保持来源坐标和原值。
- 从来源核对中增加规格变体身份、重复价格标签的明确角色、固定范围变化保护及 Excel 错误价格门禁；这些合同同步贯穿检索与 PPT。
- 映射按来源登记并复用；结构预期不符立即报错，不猜测补齐。原 XLSX 不改写，也不另造标准化 XLSX。
- 维护助手短入口和按需子代理分工，独立调查只读；写库和最终交付由主代理串行完成。

## 风险与边界

- 相同表头不保证语义相同；映射需由 Codex 结合样本确认。
- 合并区域内价格冲突不能拼成一个价格，需重新选择记录粒度。
- 未归属或不可解析的图片显式提示，可按无图出图；不联网猜图。
- 私有映射、产品资料与试验结果留本地，公共测试仅用合成资料。
- 不承诺一次覆盖所有异形表。相同结构验证通过后停止追调；剩余失败保留原因。

## 验收

1. 原有检索、增量、价格、来源校验保持有效。
2. 行式/合并/重复块在不同品类资料上可复用；新增中秋表作为另一来源验证。
3. 同一映射能够复用更新后的数据，遇到表头位置变化明确失败。
4. 缩小观察范围能减少返回内容；无需把整库卖点交给模型。
5. 选取跨来源产品生成并逐项核对唯一 PPT；复核名称、价格、图片所属和完整详情。
6. 代码与公共历史扫描通过后同步仓库。

## 步骤

结构探针与契约测试 → 共用记录投影/图片适配 → 映射登记与 CLI → 真实样本验证 → Codex/子代理路由文档 → 单文件交付与公开检查。

## 本轮验收记录

- 10 个实际工作簿、43 张工作表全部完成映射/入库，2524 条记录；变体与来源重复保留。主索引复用这些映射，没有按供应商加解析分支。
- 21 个合成测试覆盖增量、合并、重复块、结构漂移、变体、错误价格、紧凑观察和公开边界；重复卡片的实际外部样本已不在原位置，未宣称其真实数据通过。
- 回查 12350 个源标量值、2670 个图片引用的哈希；跨来源 5 款/6 页内部 PPT 通过数据比对和版面抽查。
- 源表仍有空值、带单位/多配置价格和少量缺图，保留诊断与原文；不猜算、不补图、不承诺源表商业内容正确。
- 工具内部时间与 Codex 语义分析时间分开；日常结果按数量/字段/字符预算返回。内部验证产物清理，客户交付目录保持一份 PPT。
